# Processed Data

### 1. General Information

This folder contains processed data ready for visualization in a real-time data dashboard. There will only be 4 files within
this folder, with each corresponding to one of the instruments / data tables (EXO, ADCP, Rad7, LICOR). 

Processing will extract the specific columns to use in the dashboard, perform any necessary unit conversions, and subset the
data tables to a specific length of time to maximize app performance (i.e. past 100 days only).

Metadata to consider for naming convention:

  * L0 - close-to-raw data for rapid QAQC
  * L1 - data with metadata for preliminary analyses

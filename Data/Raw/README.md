### 3. Notes

Metadata to consider for naming convention:

* Timestamp
* Instrument / Datetable (EXO / ADCP / Rad7 / LICOR)
* Project name / Location
* Version
  * Raw - as downloaded from data loggers
  * L0 - close-to-raw data for rapid QAQC
  * L1 - data with metadata for preliminary analyses
  * L2 - refined data ready for models and analyses
